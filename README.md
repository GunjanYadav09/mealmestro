🍽️ MealMaestro
LINK : https://sage-phoenix-105564.netlify.app/

📖 Description
MealMaestro is a comprehensive meal planning and recipe management web application designed to simplify your kitchen routine. Plan meals, track pantry inventory, generate shopping lists, and discover new recipes - all in one intuitive platform.

✨ Features
📋 Smart Meal Planning - Schedule meals for the week with drag-and-drop simplicity

🛒 Automated Shopping Lists - Generate grocery lists based on your meal plans

🥫 Pantry Management - Track ingredients, expiry dates, and stock levels

📚 Recipe Collection - Save, categorize, and search your favorite recipes

📱 Responsive Design - Works perfectly on desktop, tablet, and mobile devices

⚡ Real-time Updates - Instant sync across all your devices

🛠️ Technologies Used
Frontend: HTML5, CSS3, Vanilla JavaScript

Version Control: Git & GitHub

Deployment: GitHub Pages

Icons: Font Awesome

Styling: Custom CSS with modern design principles
